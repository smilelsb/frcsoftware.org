## Java 课程

- [Codecademy](https://www.codecademy.com/learn/learn-java)：在浏览器里交互式学习 Java，并完成配套练习。
- FIRST 的 Java 培训：FIRST 官方的 Java 编程培训。
    - [第 1 部分](https://training.firstinspires.org/courses/java-programming-part-1)
    - [第 2 部分](https://training.firstinspires.org/courses/java-programming-part-2)
- [Mooc fi 的 Java 课程](https://java-programming.mooc.fi/)：赫尔辛基大学的免费 Java 课程，包含大量编程练习。
- [Java 的 Learn Java](https://dev.java/learn/)：dev.java 上的 Java 入门学习路径。
- [Oracle 的 Java 教程](https://docs.oracle.com/javase/tutorial/java/)：Oracle 官方的 Java 语言和标准库教程。
- [7237 Unibots，Java Basics](https://www.youtube.com/playlist?list=PLbyD6UONF3m7Tvp6mTluAtD8vSv2MeO8o)：7237 队制作的 Java 基础视频系列。

## Java 参考资料

- [W3Schools](https://www.w3schools.com/java/)：按主题查阅 Java 语法和短示例。
- [GeeksForGeeks](https://www.geeksforgeeks.org/java/java/)：Java 概念、语法和示例文章。

## 练习

- [Coding Bat](https://codingbat.com/java)：针对基础逻辑的小型 Java 练习题。
- [CodeWars](https://www.codewars.com/)：按难度分级的编程挑战。
