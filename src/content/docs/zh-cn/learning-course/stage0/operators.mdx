Java 使用运算符来改变或比较变量的值。
运算符有四种：

- Arithmetic Operators（算术运算符）
- Assignment Operators（赋值运算符）
- Comparison Operators（比较运算符）
- Logical Operators（逻辑运算符）

### 注意等号！

使用比较运算符时，务必使用双等号 `==`，而不是单个等号 `=`。
与数学中不同，单个等号表示赋值。

在下面的示例中，打印语句不会运行。
你会收到一条错误信息，说明赋值符号的左侧必须是变量。
{/* rli:ignore */}

```java
    System.out.println(6 = 8);
```

加上双等号后，错误就会消失，因为编译器会把它理解为比较左侧的值和右侧的值。
这会输出 `false`，因为 6 不等于 8。
{/* rli:ignore */}

```java
    System.out.println(6 == 8);
```

## Logical Operators（逻辑运算符）

逻辑运算符通过 true 或 false 语句帮助程序做出判断。
它们也会在条件语句中使用。

<Aside type="note" title="Note（备注）">
    逻辑运算符也遵循运算顺序（称为 PEMDAS），可以使用括号改变这个顺序。
</Aside>

<table class="Comparison Operators">
    <thead>
        <tr>
            <th>运算符</th>
            <th>说明</th>
            <th>示例</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>`&&`</td>
            <td>与：两个语句都为 true 时，结果为 true</td>
            <td>`true && true // this is true`</td>
        </tr>
        <tr>
            <td>`||`</td>
            <td>或：至少一个语句为 true 时，结果为 true</td>
            <td>`true || false // this is true`</td>
        </tr>
        <tr>
            <td>`!`</td>
            <td>非：取反。true 会变成 false，false 会变成 true</td>
            <td>`!true // this changes to false`</td>
        </tr>
    </tbody>
</table>
