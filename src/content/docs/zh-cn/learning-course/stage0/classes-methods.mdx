在[上一课](/learning-course/stage0/classes-objects/)中，我们编写了带有 fields（字段）、constructor（构造函数）和 getters（获取方法）的 `Point` 类。
它可以保存一对坐标，但不能对坐标做任何处理。
本课要编写 <strong>methods（方法）</strong>，用来定义类的行为，
然后再构建一个状态会随时间变化的类。

## 编写方法

方法是定义在类内部的一段代码。
方法用于定义类的行为。
我们已经见过两个方法示例：`String` 类中的 `length()`，以及我们在 `Point` 上编写的获取方法。
方法可以有参数，也就是调用方法时传入的值。

方法结束后，可以把一个值交还给调用者，这称为返回一个值。
要返回一个值，方法体使用 `return` 关键字，后面跟着要返回的值。
`return` 语句一旦运行，方法会立刻停止执行，并把该值交还给调用者。
例如，`String` 类中的 `length()` 方法返回字符串的长度，
并且没有参数。

方法的一般语法是：

{/* rli:ignore */}

```java
public ReturnType methodName(ParameterType1 param1, ParameterType2 param2, ...) {
    // method body
}
```

方法可以有任意数量的参数，包括没有参数，参数也可以是任何类型。
`ReturnType` 是方法返回值的类型，例如 `length()` 的返回类型是 `int`。
方法不一定要返回内容。如果不返回任何内容，
就使用返回类型 `void`。`void` 是一个关键字，表示方法不返回任何内容。
`void` 方法仍然可以单独使用 `return`、不带值，以便提前停止。
但更常见的做法是完全省略它，因为方法到达末尾后会自己结束。

让我们给 `Point` 添加一些行为，先从 `plus` 方法开始。
`plus` 方法接收另一个 `Point` 对象作为参数，
并返回一个新的 `Point` 对象，它是两个 `Point` 对象之和。

```java {point}#plus

```

这里的 `other` 只是我们为方法参数选择的名称，也就是要相加的另一个 `Point`。
`this` 仍然指调用 `plus` 的那个 `Point`，与构造函数中相同。
因此，`this.x` 和 `this.y` 是调用 `plus` 的那个 `Point` 的坐标，
`other.x` 和 `other.y` 是传入的 `Point` 的坐标。

在这个方法中，我们使用 `new` 关键字创建一个新的 `Point` 对象。
因为前面定义的构造函数接收两个参数，
所以把 `this.x + other.x` 和 `this.y + other.y` 作为实参传给构造函数。
因此，新的 `Point` 对象会拥有两个 `Point` 对象坐标之和。

## Mutable State（可变状态）

我们定义的 `Point` 类是 <strong>immutable（不可变）</strong> 的。这意味着 `Point` 一旦创建，
它的 `x` 和 `y` 值就永远不能改变，因为这些字段是 `final` 的。
不可变通常是一件好事：它让类更容易理解，因为你不用担心值会意外改变。

不过，有时我们需要一个状态会随时间变化的类。
来定义一个 `RobotTracker` 类，用于跟踪机器人在场地上的当前位置。
位置从某个地方开始，并随着机器人移动而更新，因此它不能是 `final`：

```java {tracker}#mutableField

```

注意，字段的类型不必是 <strong>primitive type（基本类型）</strong>，例如 `double`。
就像 `x` 和 `y` 是 `double` 字段一样，`position` 是一个字段，它的类型是我们自己的 `Point` 类。
任何类型，无论是 Java 内置的，还是我们自己定义的，都可以用作字段类型。

我们仍然使用 `private`，防止其他类直接修改这个字段，
因此改变位置的唯一方式是通过我们定义的方法。
这很重要，因为 `move`、`distanceTo` 和 `reset` 可以依赖 `position` 始终有效，
而不用担心另一个类把它设成意外的值。
如果外部代码能够直接进入并覆盖 `position`，`RobotTracker` 就无法保证自己的行为。

构造函数的工作方式与之前相同，把 `position` 初始化为给定的起始值：

```java {tracker}#robotTrackerConstructor

```

只要每个构造函数接收的参数组合不同，一个类就可以有多个构造函数。
当存在合理的默认值时，这很有用：这里，不带参数的 `RobotTracker` 从原点开始。
我们不重复写 `this.position = Point.ORIGIN`，而是使用 `this(...)` 调用另一个构造函数：

```java {tracker}#constructorChaining

```

调用 `move` 时，传入一个 `delta`，也就是位置的变化量，方法会把它加到当前位置上。
这就是在改变状态，因为方法重新赋值了 `this.position`，从而改变了对象的状态：

```java {tracker}#stateMutation

```

注意，`move` 方法的返回类型是 `void`。
这是因为该方法实际上不需要返回任何内容。
它改变的是自己的内部状态。

`distanceTo` 计算从当前位置到目标的直线距离。
它使用局部变量 `diff` 保存两点之间的向量，然后再取这个向量的长度：

```java {tracker}#localVariableChain

```

因为 `position` 是私有的，所以还需要一个获取方法来读取机器人的当前位置：

```java {tracker}#getPosition

```

`reset` 把位置设回原点。
我们不写 `new Point(0, 0)`，而是复用 `Point.ORIGIN` 常量。
两种写法都可以，因为新的 `Point(0, 0)` 与 `Point.ORIGIN` 坐标相同。
但复用 `ORIGIN` 可以避免创建一个多余的对象，也让代码的意图更清楚：
我们明确指的是原点本身，而不是一个碰巧位于 (0, 0) 的点：

```java {tracker}#useStaticConstant

```
