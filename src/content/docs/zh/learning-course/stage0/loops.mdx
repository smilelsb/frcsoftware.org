代码中经常需要连续重复同一个动作。
例如，如果你知道成绩即将公布，可能会反复查看，直到成绩出来。
在 Java 中，可以用循环来完成这种重复。

本课介绍两种主要循环：**while** 循环和 **for** 循环。

<Aside type="note" title="Note（备注）">
    另一种循环是 do-while 循环。由于它在 FRC 中很少使用，这里不会介绍。
    如果想进一步了解 do-while 循环，可以查看 [w3schools
    教程](https://www.w3schools.com/java/java_while_loop_do.asp)。
</Aside>

条件语句和循环看起来可能相似，但用途不同。
条件语句和循环都控制程序的执行流程。
条件语句用于把一段代码运行一次，而循环可以把一段代码运行多次。

## while

`while` 循环是最简单的循环。

`while` 循环的语法如下：

```java #whileSyntax

```

你可能会注意到，`while` 循环看起来很像上一课介绍的 `if` 条件语句。
`while` 循环包括：

- `while` 关键字，用来声明正在创建 `while` 循环
- `( )`，用来放置结果为 true 或 false 的条件。
  例如，(5 > 1) 是一个条件，而且为 true，因为 5 大于 1
- `{`，表示循环代码块的开始
- `}`，表示循环代码块的结束

和 `if` 条件语句一样，条件为 true 时，`while` 循环会运行它的代码块。
不过，与 `if` 条件语句不同的是，代码块运行完后，`while` 循环会再次检查条件。
如果条件仍然为 true，代码块会再次运行。
这个过程会重复，直到条件变为 false。
另外，与 `if` 条件语句不同，`while` 循环（或其他任何循环）不能附带 `else` 语句。
这意味着，如果第一次遇到循环时条件就是 false，整段循环都会被跳过。

来看一个示例：

```java #whileExample

```

在示例中，有一个名为 `i` 的 `int`，它的值是 0。`while` 循环的条件是 `i < 6`。
首先，编译器检查条件是否为 true。
我们知道 0 小于 6，所以 `while` 代码块会运行，并把 `i` 的当前值 0 输出到终端。
`i++` 也会更新 `i` 的值，使它变为 1。
现在条件检查 1 是否小于 6。我们知道结果为 true，所以会输出 `i` 的值，并把 `i` 加 1。
这个过程不断重复，最终 `i` 的值变为 6。
此时再检查条件，结果为 `false`，因为 6 并不小于 6，循环结束。

结合前面的示例，可以看到 `for` 循环的语法包括：

- `for` 关键字，用来声明正在创建 `for` 循环
- `()`，用来放置让循环运行的三条语句
- `{`，表示循环代码块的开始
- `}`，表示循环代码块的结束

这三条语句是：

- **initialization（初始化）**：创建一个变量，设定循环的起点。
  在前面的示例中，这就是 `int i = 0;`。
- **condition（条件）**：每次循环前都会检查的条件，它使用前面创建的变量。
  这就是 `i < 6;`。
  如果条件为 true，循环内的代码就会运行
- **update（更新）**：每次循环后更新初始化时创建的变量。
  最后，这就是 `i++`。

这 3 条语句都是可选的，但分号必须保留。
不过，本节的示例会使用全部语句。

然后回到更新语句 `i++`，`i` 增加 1，现在 `i` 的值是 1。
我们检查条件，1 小于 5，所以 `for` 代码块再次运行，输出 `i` 的新值，然后更新 `i`。这个过程重复，直到 `i` 不再小于 5。
当 `i` 不再小于 5 时，就会跳过 `for` 循环。

## 小心无限循环

必须确保条件能够变成 false。
如果条件始终为 true，循环就会一直运行，形成无限循环。
出现无限循环时，代码永远不会停止。
如果代码正在运行机器人机构，这可能不安全。
它可能让机器人一直向前行驶，或者让机械臂一直运动。
只要确保条件中的值会通过加 1 或减 1 发生变化，就可以避免无限循环。

<Aside type="note" title="Note（备注）">

深入学习 FRC 编程后，你会发现无限循环有时是被鼓励的（例如在命令中）。
阶段 1 会进一步介绍这一点。

</Aside>

{/* rli:ignore */}

```java
    int timer = 0;
    if (false) {
        while (timer < 7){
            drivetrain.setThrottle(1); // sets drive motors to full speed
        }
    }
```

在这个示例中，我们希望底盘行驶 7 秒。
变量 `timer` 被设为 0。
0 小于 7，所以内部代码运行，机器人全速向前行驶。
但是，`timer` 的值从未改变。
这意味着 `timer` 始终是 0。0 小于 7，所以循环会持续运行，机器人永远不会停止行驶！

要修复这个问题，需要像下面这样增加计时器的值。

{/* rli:ignore */}

```java
    int timer = 0;
    while (timer < 7){
        drivetrain.setThrottle(1); // sets drive motors to full speed
        timer++; // increments timer by 1
    }
```

现在每次运行循环时，`timer` 都会加 1，机器人会在 7 秒后停止行驶。
